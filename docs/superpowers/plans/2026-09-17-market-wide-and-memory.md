## 约束与决策

- 沿用当前 codex/disk-collector 分支及未提交工作，不移动 checkout 或热改嵌入端。
- 现有 M1a 证明命名共享内存缺少已知可靠同步原语；不使用文件锁或整数写入冒充。
  验证已批准的命名管道备选。外部 server 用显式当前用户 DACL，拒绝远程客户端；
  内置端仅依赖已有 _winapi，用 overlapped I/O 在 QMT 回调有界推进。
- 通道帧上限 256 KiB，发送队列上限 8，未完成读写各最多一个；无阻塞等待。
  版本、会话、方向序号、双向 HMAC-SHA256 随机挑战及 SHA256 帧完整性校验；
  会话配置以私有 ACL 保存，并验证祖先目录不能被其他普通用户替换。
- 探针先跑合成消息，至少 10,000 条逐条核对；无行情调度、错误注入、权限、关闭和
  用户控制的策略停止/重启均需证据。未执行门禁保持 incomplete。
- 行情只读：先 get_full_tick，再指定证券订阅/退订与健康失效；无账户或交易功能。
- 全市场任务必须冻结真实 QMT 板块成员快照，记录缺失/失败而非删掉证券；长任务
  分批、持久续采，单请求有界。旧历史队列每秒一请求，吞吐实测后报告预计时长。

## 独立任务及接口

1. **历史全市场与复权（子任务）**：新增 market_collector 模块、CLI 和测试。
   复用原 collector/AutomaticBackend；真实板块清单、证券去重快照、分片持久报告、
   单元错误分类和继续执行；复权因子七字段、事件日期、合法空事件明确记录。
   不修改当前 qmt_bridge 任何现有 worker，不启动批量下载直到主任务统一调度。
2. **外部管道与权限（子任务）**：pipe_security.py、pipe_server.py、Windows 真管道测试。
   Server(name): accept_nonblocking()->PipeIO|None, security_report(), close()。
   调用 _winapi 及 ctypes；权限检查/拒绝广泛访问/资源关闭测试必须真实执行。
3. **内置协议/I/O/探针（主任务）**：memory_protocol_v1.py、memory_io_v1.py、独立
   strategy_memory_v1.py；外部 qualification runner。PipeIO(api, handle) 提供
   send(bytes)、poll(limit=8)->list[bytes]、close()。协议独立字面量测试，Python 3.6 语法。
4. **行情与验收（依赖 2/3）**：通过通道验收后追加只读行情端点与用户端，验证快照、
   持续更新、时间/序号、健康/失联、恢复和外部归档；需要 QMT GUI 时提供准确步骤。
